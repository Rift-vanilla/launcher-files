# launcher-files

Файлы для Rift Launcher.

**Скачать лаунчер:** Releases → последний релиз `v…` → `Rift-Launcher-Setup-….exe`.
Релизы `v…` публикуются автоматически из приватного репозитория с кодом; по ним же лаунчер обновляется у игроков.
Релизы с файлами сборок (`files-…`) выкладываются с флагом `--latest=false`, чтобы «последним» всегда оставался лаунчер.

- **`manifest.json`** — единственный файл, который читает лаунчер. Отсчёт (`season.opensAt`), текст Core AI (`coreAi`),
  погода (`weather`) и новости (`news`) правятся **здесь**, прямо на GitHub. Игроки увидят изменения при запуске лаунчера
  (или в течение 10 минут, если он открыт).
- Описание сборок и генератор списка файлов лежат в репозитории rift-launcher (`manifest.base.json`, `tools/make-manifest.js`);
  генератор сохраняет тексты, уже написанные в этом `manifest.json`.
- Сами файлы сборок (моды, ресурспаки, конфиги) лежат в **Releases** этого репозитория.

Как выпустить обновление сборки — см. README в Rift-vanilla/rift-launcher, раздел «Как выпускать обновление сборки».

## Файлы сборки

- `files/vibe/` — моды и ресурспак серверной сборки Rift Vibe+ (Minecraft 26.1.2), ссылки на них прописаны в `manifest.json`.
- `files/variants/26.2/` — те же моды под Minecraft 26.2 для своих сборок игроков.
- Fabric API не хранится здесь: лаунчер берёт его с Modrinth под нужную версию игры (`modrinthFiles`).
- Обновил файл — пересчитай `sha1` и `size` в `manifest.json`, иначе лаунчер откажется его ставить.
